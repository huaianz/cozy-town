# 田舍小镇（Cozy Town）

一款用 Unity 做的中式田园像素经营小游戏：种田、养鱼、挖矿、做饭、接委托，一边还债一边把荒地盘活。
目标平台是**抖音小游戏（WebGL）**与 **Android**，操作以手机触屏为主。

---

## 玩法概览

开局是一片荒地，你在老镇长那里背下三期地契钱（500 / 2000 / 5000 金币），
靠种地、钓鱼、挖矿、做饭、交委托一点点把日子过起来，顺便把果园、矿洞、鱼塘一块块开荒出来。

### 核心循环

1. 锄地 → 播种 → **去水井打水** → 浇水 → 收获 → 卖钱 / 交委托
2. 白天干完活后睡觉推进一天，第二天早上弹出「夜结算」：作物长到哪了、鱼成熟几条、矿脉刷新、今天天气与今日建议
3. 攒材料升级工具（3×3 浇水、更多耐久）与开荒新区域，形成"时间换钱、钱换时间"的正循环

### 已实现的系统

| 分类 | 内容 |
| --- | --- |
| 农田 | 锄地、播种、浇水、收获、未开荒格、开荒证、随机野草、丢荒恢复 |
| 水与工具 | **水井打水**（水壶初始 2 次水，升级后 3/4 次）、工具耐久、工坊升级与一键修复 |
| 季节天气 | 四季（1-3 月春 / 4-6 月夏 / 7-9 月秋 / 10-12 月冬）、四季天气池、雨天自动浇水、雷雨毁苗、稻草人防护、雨后田里冲来掉落物 |
| 果园 | 果树随季节换装（春嫩绿花苞 / 夏深绿青果 / 秋结果可采 / 冬落叶）、大风暴雨落果、砍树留树墩、木材掉落拾取 |
| 矿洞 | 随机矿脉、三天换位恢复、多矿种、镐子挖矿、矿石用于升级 |
| 鱼塘 | 投鱼苗、撒鱼食、丢野草（草鱼加成）、逐日成长、成熟后钓鱼小游戏、雨天水波纹 |
| 生活 | 烹饪 6 种配方、集市日（每 7 天卖价 ×1.5）、装饰摆放与镐子拆除 |
| 发展 | 委托（1~3 天期限、每天刷新、HUD 显示剩余天数）、图鉴（分类收集，获得过即永久记录）、成就与卖价加成、农场等级 |
| 主线 | 三期债务与地契面板、三封回忆信、开场五幕剧情、区域开荒（果园→矿洞→鱼塘） |
| 节奏 | 每天只能睡一次且 18 点后可睡、**体力耗尽可提前休息**、睡前夜结算面板 + 今日建议 |

## 操作说明

### 手机（主要）

- 点击地块使用当前选中的工具／物品（背包里点选）
- 右下角按钮栏：睡觉 / 委托 / 烹饪 / 工坊 / 图鉴 / 地图 / 设置 / 地契 / 开荒
- 按钮栏左侧的 `>` / `<` 箭头可以把整排按钮收起或放出，避免挡住视野
- 双指缩放、拖拽平移视角；「地图」面板可以快速跳回各个区域

### 电脑调试快捷键

| 按键 | 作用 |
| --- | --- |
| `E` | 交付委托 |
| `B` | 打开地契面板 |
| `K` | 打开开荒面板 |
| `M` | 加 1000 金币（测试用） |
| `N` | 时间跳到 18:00 |
| `H` | 触发主线剧情 |
| `Y` | 重播开场五幕 |
| `L` | 解锁全部区域 |
| `G` | 直接推进一天 |
| `T` | 按住加速时间流逝 |

## 工程结构

```
Assets/
  Scripts/                游戏逻辑（全部 C#）
    Grid/                 农田地块、点击交互、天气伤害与生长
    Areas/                果园 / 矿洞 / 鱼塘 / 区域开荒 / 水井 / 装饰
    Inventory/            背包与物品
    shop/                 商店、委托
    Cursor/               光标有效性判定
    Settings/             音频、设置面板
    其他                  时间、天气、事件、HUD、各功能面板
  Resources/
    Art/                  贴图（果树、矿脉、装饰、图标等）
    Audio/BGM/            四季背景音乐（ogg）
    Audio/SFX/            音效（wav，同名带 _2/_3 为随机变体）
    Prefabs/              果树、浮标等预制体
    Front/                中文像素字体
  Scenes/                 StartScene（主菜单）、GameScene（游戏主场景）
  Editor/                 构建脚本、导入规则、编辑器辅助
  Data_SO/                物品、作物、商店等数据表
```

## 开发与构建

- **Unity 版本**：2021.3.45f2c1（URP，2D）
- 打开工程：用 Unity Hub 添加本目录，进入 `Assets/Scenes/StartScene.unity` 运行
- 打包 WebGL（抖音小游戏基础包）：
  `Unity.exe -batchmode -quit -projectPath <工程路径> -buildTarget WebGL -executeMethod BuildHelper.BuildWebGL -logFile build.log`
- 打包 Android APK：
  `... -buildTarget Android -executeMethod BuildHelper.BuildAndroid`
- 抖音小游戏：先出 WebGL 包，再用抖音开发者工具转换并填入 AppID（桥接脚本在 `Assets/Plugins/WebGL/DouyinBridge.jslib`，对应 C# 封装 `DouyinBridge.cs`）
